# Personas & Roles Update Checklist

Use this checklist when adding or updating a persona in docs/octoacme-roles-and-personas.md

- [ ] Role name and short summary added (1–2 lines)
- [ ] Key responsibilities documented (5–8 bullets)
- [ ] Primary interactions with existing roles defined
- [ ] Success criteria / goals added (how we’ll know the role is effective)
- [ ] Suggested communication cadence or handoff points included
- [ ] Reviewed for overlap with existing personas (merge or clarify overlaps)
- [ ] Stakeholder(s) / domain owner identified and notified
- [ ] Added to Table of Contents or referenced from project README if required
- [ ] Changes reviewed in a PR and linked to an issue for traceability
